# 多窗口与终端生命周期

终端属于项目，由 daemon 持有进程；窗口只决定展示位置。一个终端最多在一个窗口中接受交互，其他窗口可以看到其入口和归属。

## 用户操作

- 新建窗口先选择项目，默认指向来源窗口的项目。选择已有其他窗口终端的项目仍可新建自己的终端。
- 项目标题选择项目，箭头只展开列表，加号创建终端。展开列表包含本窗口、其他窗口和后台终端。
- 点击其他窗口的终端跳转并聚焦；点击“移入”把同一个终端转到当前窗口。
- 标签页菜单支持移到现有窗口、移到新窗口、留在后台；跨窗口拖放与拖出窗口使用同一事务。
- 所有关闭窗口入口都保留终端在后台。关闭标签页会结束终端，有活跃命令时确认。
- 退出 Eggie 保留后台进程；“结束全部终端并退出”明确结束全部项目的进程。
- 全局终端搜索 `⌘⇧K`、窗口选择 `⌘⌥W`、撤销窗口操作 `⌘⇧T`。原来的关闭窗口快捷键仍是 `⌘⇧W`。
- 项目删除和结束项目全部终端包含其他窗口与后台，操作期间禁止新建该项目的终端。

## 侧边栏布局

“设置 → 常规 → 侧边栏布局”保存为全局界面偏好 `sidebar_layout`，默认 `all_projects`。`single_project` 在顶部以下拉框选择当前窗口的项目，列表与主面板共用 `active_project`，不额外保存筛选项目。两种布局共用终端行与其他窗口/后台分组；单项目模式忽略展开/收起状态，切回全部项目时保留原状态。布局切换不移动或关闭终端。

项目下拉框复用原生 popup 窗口，支持方向键、Enter、Escape 和点击外部关闭。切换布局、项目目录变化、主窗口移动或失活时关闭；打开菜单时取消悬停预览，避免多个弹窗重叠。

## 模型与事务

`eggie-domain::PresentationWorkspace` 保存全部窗口和后台标签页。`WindowPresentation` 使用稳定 ID 与窗口编号，每个项目拥有独立布局；`BackgroundTerminal` 保留标签 ID、自定义标题和 profile。

移动先在候选模型中验证源、目标和项目，再整体提交。GUI 通过每窗口版本号发布状态，避免迟到的源窗口通知覆盖移动结果。所有 UI 导航都在点击发生时解析当前归属。

撤销记录展示操作前后状态，只恢复被操作涉及的窗口，保留之后新开的窗口和终端；明确结束的会话从历史中剔除，撤销不会启动新进程。协议消费游标不随展示撤销倒退。

`workspace-v2.json` 一次原子保存全部窗口、位置、项目、分屏、侧栏和后台标签。应用退出保存打开的窗口，重启恢复全部窗口和最后活跃窗口；关闭窗口则保存后台状态。已失效的终端保持“已结束”入口，不自动重启命令。损坏文件隔离保存。

这次有意采用新恢复格式：daemon 不再知道 WindowId，没有 ClaimSession / DetachWindow，不读取旧单窗口 workspace.json。旧文件保留。当前使用 IPC v4，GUI 与 daemon 的兼容性由协议版本决定，开发 GUI 重建也保留兼容 daemon 的运行进程；build ID 用于诊断，不再触发进程销毁。

## 后台事件与弹出窗口

全局目录每 500 ms 同步一次；每个会话的 OSC、进度订阅由应用持有，与窗口关闭、转移无关。OSC 游标随工作区保存，窗口移动不会重新消费通知或剪贴板事件。明确结束的会话有墓碑保护，迟到的目录响应不能重新引入它。

原生 popup 是窗口的临时附属展示。项目列表延迟 320 ms 出现、220 ms 离开关闭；终端预览延迟 850 ms，画面每 300 ms 更新、进程内存约 900 ms 更新，状态读取应用目录。点击在释放鼠标时提交；支持项目 popup 键盘导航和 Escape；跟随主窗口生命周期，尊重减少动态效果设置。

## 验证

领域测试验证移动身份、失败回滚、关闭/恢复与序列化；GPUI 测试验证窗口版本、独立窗口修改、撤销、迟到目录和全部窗口的原子恢复；真实 PTY 测试验证移动/关闭/恢复前后的 PID 和输出连续性。跨显示器、全屏 Space 和动画观感仍需要人工验证。
