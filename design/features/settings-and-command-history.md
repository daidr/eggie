# 设置查找与命令历史

状态：当前工作区实现

## 设置查找

设置侧栏提供搜索框，按中英文标签、关键词和多个空格分词筛选。
结果显示所属分类；点击或 Enter 跳到对应设置。第一条默认选中，方向键立即切换，Esc 清空。
隐藏设置先定位到其前置控制：自定义终端主题定位到主题来源，SSH 字段定位到连接方式。
定位使用 GPUI ScrollAnchor 记录的真实控件边界，应用滚动后请求重绘，不估算滚动距离。

只构建当前分类或搜索结果，沿用现有设置与选择器组件；不为了搜索加载隐藏主题预览。

## 命令历史

右侧“命令”面板可搜索当前终端的命令。点击仍只回填，不执行。
右键菜单提供定位输出、复制输出、复制命令及输出。
等待输入的 prompt 不显示为运行中的命令。

输出来自 daemon 已有回滚缓冲，不额外保存一份输出日志。
OSC 133 的 C/D 标记划定命令范围；输出缺失或回滚淘汰时返回错误。
记录数量受命令历史上限约束，读取上限 1 MiB，超出时明确提示截断。
不为无 shell integration 的终端猜测命令边界，不提取替代屏幕中的命令输出。

命令范围通过终端核心已有的临时 reflow anchor 跟随宽度变化，resize 完成即移除标记；
高度变化仅平移坐标，避免每次扫描整个回滚区。空输出不固定已清除的 prompt 行。
中文、软换行和 Tab 提取复用内核文本逻辑，复制不会把自动换行变成额外换行。

## 信息层级

项目名称用强调色标明当前项目，叶子终端行显示选中背景。
信息页已取得进程列表时，不在顶部重复显示同一进程和 PID；初始目录收进可展开区域，
当前目录及打开/复制操作保持直接可见。
