# SSH 与端口转发

状态：现行设计。整理于 2026-10-16，基础实现提交为 `3b756bb`，配置发现与诊断见当前工作区。

## 目标与入口

SSH 是终端 profile 的一种连接方式，使用系统 OpenSSH 的别名、密钥和跳板配置。
普通本地终端不展示 SSH 端口管理；端口属于当前远端上下文，不设独立顶层页或额外目标下拉框。

## 连接与恢复

- profile 中清空 SSH 主机仍保留 SSH 类型；未通过校验时不能启动，不能意外降级为本地 shell
- 编辑中的无效配置留在表单，不覆盖最后保存的有效连接
- 认证交互留在终端；连接中可取消，失败和断开保留输出并提供重连
- 重连复用原始启动配置和最后远端目录，保留标签位置与自定义标题；启动的是新远端 shell，不承诺恢复远端旧进程
- 新标签和分屏在相同目标下继承远端目录；profile 明确配置的目录优先
- 普通进程结束默认移除标签；需要 SSH 恢复的终端是例外，保留故障上下文

连接状态叠在终端内容上方，不挤压终端布局。状态卡有状态图标，使用与终端查找相同的
浮层表面、边框、阴影和连续圆角；两者同时出现时保持一致。

## Host 配置与错误诊断

profile 保留自由输入主机，同时提供现有搜索选择器列出 SSH 配置中的字面 Host 别名。
发现过程读取用户和系统配置及 Include，支持引号与 glob，去重并避免递归循环；
不执行 Match exec，过滤通配符/否定模式，最多 64 个文件、2 MiB 配置与 1024 个别名。

“查看连接配置”显式调用系统 `ssh -G`，尊重 HostName、User、Port、IdentityFile、
ProxyJump 与 ProxyCommand，显示实际值，不把解析结果写回覆盖原配置。解析在后台，
有 3 秒执行上限；不建立 SSH 网络连接。OpenSSH 可能按用户配置评估 Match exec，
因此不在每次编辑或页面 render 时自动解析。切换 profile/目标后不显示旧目标的结果。

失败状态从已有终端输出识别认证、主机密钥、主机解析、超时、端口拒绝与网络中断，
提供简短纠错方向；未知错误保留通用失败提示与原始终端输出，不自动修改 known_hosts、
密钥或 SSH 配置。解析结果在进程结束后缓存，不反复扫描终端。

## 服务与映射

信息面板展示远端身份、目录、发现的服务和已有映射。服务提供直接转发入口；映射显示真实
本机地址，并按状态提供打开、复制、停止、重试、移除等操作。高级选项按需展开，错误就地呈现。

进程与服务检查仅在信息面板或终端预览需要时运行；同一远端目标共享检查缓存。
本地检查共享每秒按需更新的系统进程快照，同一进程树的端口查询在一秒内复用；
不再为每个终端保留完整系统进程数据库，端口缓存最多保留 64 个进程树。
端口行有稳定 ID，指针进入时直接高亮。

## 实现边界与验证

- `crates/eggie-daemon/src/ssh/`、`remote_bootstrap.rs`：连接、检查、端口管理和远端集成安装
- `crates/eggie-ui/src/app/ssh.rs`：连接状态与目录继承
- `crates/eggie-ui/src/app/ports/`、`ports.rs`：当前终端的映射编辑与操作
- `crates/eggie-ui/src/workspace.rs`：重连后的会话替换与展示身份

验证本地终端无 SSH 管理入口；SSH 有效/无效输入、取消、失败、断开和重连；映射的端口冲突、
自动选择地址、停止及恢复；同时展示搜索和状态卡时的视觉一致性。真实远端验证须有可用的测试目标。

2026-10-17 在 dev 应用检查了现有 SSH 配置的别名选择器与有效配置展示，确认主机、用户、
端口及密钥路径可正常读取；未修改用户配置或建立测试 SSH 连接。别名 Include/glob 与
OpenSSH `-G` 参数覆盖有独立测试，本轮没有重跑完整远端重连/转发回归。
