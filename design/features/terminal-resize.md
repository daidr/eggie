# 终端尺寸变化与 prompt 重绘

状态：现行工作区设计。整理于 2026-10-16。

## 用户行为

窗口、侧栏或分屏改变尺寸时，已完成的输出按终端内核规则重排；活动 prompt 和输入由 shell
重绘。重复缩放不能在 prompt 上方累积空行或旧 prompt 副本，也不能删除真实命令输出。
备用屏幕应用使用原生 resize；仅行数变化时不清除 prompt。

## 坐标与所有权

daemon 的 PTY I/O 线程将尺寸变化与输出字节送入同一 parser 队列；已读的旧尺寸输出先解析，
随后改变内核几何，再解析新尺寸的输出。GUI 的 resize 确认表示请求已接受，实际生效的尺寸
由后续 snapshot 返回；不能把请求收到和内核更新视为同一时刻。

parser 在持有终端锁时读取 OSC 133 阶段和 prompt 起点。列数变化且处于 prompt/input 阶段时，
在内核 reflow 前清理活动 prompt 的旧单元格和换行标记，由 shell 按新 PTY 尺寸重绘。
清理范围从 prompt 起点到光标，不能按“空白区域”推断后删除历史。

prompt 起点是相对活动屏幕的行号，必须随屏幕滚动移动。内核 Grid 提供有符号的整屏滚动位移，
OSC 133 在解析时同步携带该位移；daemon 在标记、快照发布及 resize 前同步锚点。该计数独立于
历史容量，因此历史关闭或达到上限后仍有效。它不增加 cell 大小，不进入 GUI 的 IPC 帧或磁盘格式。

resize 本身也可能移动光标、拉回历史或压缩可见区域。完成内核 resize 后，按光标行变化重定位
prompt 起点，并重设滚动计数基准，防止把几何变化再次计作 shell 输出。列 reflow 使旧跳转索引和
输入位置锚点失效，需要清除；shell 提供的原始编辑缓冲继续保留。

## 快速缩窄

shell 的重绘不是同步调用：旧宽度的完整 prompt 可能在新的窄屏上输出，产生额外物理换行。
仅清除旧字形、修正锚点或排列解析顺序，都不能阻止 shell 连续重绘过时的中间尺寸。

在主屏幕的 prompt/input 阶段缩窄宽度时，PTY I/O 线程仅保留最新尺寸，连续请求停止 100 ms 后
统一改变 PTY 和内核尺寸。窗口和侧栏仍实时跟随拖动，短暂保留的终端内容按视口裁剪。
放大宽度、仅改变行数、输出阶段和备用屏幕应用立即排队处理，不等待该间隔。
键盘输入与粘贴会在实际写入 PTY 前提交待处理的最新尺寸，不增加输入等待。
每个会话只有一个待处理尺寸；取消缩窄或改为放大后，旧尺寸不能在稍后恢复。

## 历史问题与验证

早期修复只清掉旧 prompt 字形，但没有维护起点坐标。带历史输出的 Powerlevel10k 在多次宽高
变化后会清理错位置，逐渐留下空行；只测试单次 resize 或屏幕顶部的简单 prompt 无法覆盖。

- 单元回归：滚动后锚点变化、resize 后重设基准、重复发布不重复移动、历史为零或已满
- 真实 zsh PTY：双行和满宽 prompt，连续缩放后检查位置、历史和残留副本
- 快速单向缩窄后停住：检查最终窄屏的空行和副本，不能恢复原宽后才断言
- 缩窄中输入、取消缩窄与恢复宽度：检查实际命令看到的列数及过期尺寸的清理
- Powerlevel10k：使用显式提供的主题与配置、临时 HOME/cache，检查短历史、关闭历史、完整历史、
  连续宽高变化和快速 resize 后的空行间距、prompt 副本及已完成输出

```sh
env -u NO_COLOR cargo test -p eggie-daemon --lib resize_tests
env -u NO_COLOR \
  EGGIE_TEST_P10K_THEME=/path/to/powerlevel10k.zsh-theme \
  EGGIE_TEST_P10K_CONFIG=/path/to/p10k.zsh \
  EGGIE_TEST_SCROLLBACK=8 \
  cargo test -p eggie-daemon --lib powerlevel10k_resize_keeps_prompt_anchor -- --ignored --nocapture
```

Powerlevel10k 用例需本地安装，默认忽略；分别使用 `0`、`8`、`1000` 的历史上限验证。
测试不修改用户配置，不复用正在工作的终端；Git 状态后台服务在测试中禁用。
实际运行的修复需要新版 daemon，单纯重启 GUI 不会替换兼容协议下的旧 daemon。

2026-10-16 验证：daemon 库测试 167 项通过、6 项默认忽略；手动运行 Powerlevel10k 用例，
历史上限分别为 `0`、`8`、`1000`，每组包含 24 次宽高变化和 4 轮快速连续 resize，
prompt 空行间距与副本数量保持稳定。此项使用真实 zsh PTY，不代表所有 shell 主题均已覆盖。

后续按用户补充的“快速单向缩窄后停住”重现了旧验证未覆盖的问题：prompt 空行由 0 行增至
5 行并留下副本。新增 220 列缩至 40 列、每步 2 列、间隔 `0/1/4/8/16 ms` 的回归，
在窄屏稳定后检查，另保留普通 zsh 的自动回归及输入时最新尺寸生效的验证。

后续验证：daemon 库测试 168 项通过；三种历史容量下的五组快速单向缩窄均通过。
在 dev Eggie 的真实 SSH 终端中拖动侧栏，将视口从 85 列缩至 69 列后停住，prompt 保持
屏幕顶部、光标行保持 1、历史行数为 0；随后恢复原侧栏宽度。这是空 prompt 的界面检查，
带输出的 prompt 间距与副本数量由上述真实 PTY 回归覆盖。
