# 终端悬停预览

状态：现行工作区设计。整理于 2026-10-16。

## 入口与内容

侧边栏终端行和顶部终端标签共用一套控制器。预览展示标题、OSC 7501 或终端进度状态、
状态详情或当前目录、终端画面、前台进程与进程内存；它不接管键盘焦点，也不改变 PTY 大小。
侧边栏预览在行旁，标签栏预览在标签下方；屏幕空间不足时翻转或限制位置。

标签项及其中的 profile 色点、SSH 标记不再另弹文字 tooltip，避免与预览叠加。
新增终端、侧栏开关等独立按钮保留操作提示。标题保留 shell/程序提供的完整文本和用户自定义值，
仅由显示区域裁剪、渐变和跑马灯处理溢出，不在 GUI 数据层预先截断或补省略号。
若 shell 上报前已经缩写，跑马灯不能恢复被删掉的内容。例如 Oh My Zsh 默认
`%15<..<%~%<<` 将空闲目录标题缩成 15 个字符；这属于 shell 标题模板，与 GUI 的显示裁剪分开处理。
2026-10-16 用户确认保留 shell 标题规则，仅移除标签项 tooltip；不在集成脚本中覆盖该模板。

## 尺寸

预览使用实际字体指标和终端行列数计算画面比例，同时缩放宽高，完整显示当前网格，不裁切或拉伸。
弹窗高度由标题、详情、画面和页脚组成；画面宽高随网格比例及可用屏幕空间变化，不使用固定的
318×236 弹窗或 120 高画面。很窄的终端允许图片居中，文字区域保留基本阅读宽度。

当前约束：弹窗宽度上限 420、画面高度上限 300 个逻辑像素，并预留原生阴影和屏幕边缘空间。
小画面不放大。快照尚未取得时使用占位画面；拿到快照或行列数变化后复用同一个窗口调整尺寸。
尺寸更新不重新播放入场动画，已经关闭的预览不再接收尺寸变化。

字体测量显式接收字体、字号、显示缩放和度量调整，与终端绘制共用计算函数。
悬停计时器和异步窗口回调不进入 GPUI 的绘制期字体栈；该栈只供布局、prepaint 和 paint 使用。

## 生命周期与动效

- 首次悬停等待 850 ms；已经打开时在目标间直接切换，复用原生窗口并平滑移动
- 离开锚点和弹窗后等待 180 ms 关闭；鼠标能从锚点移入弹窗
- 侧边栏锚点与标签栏锚点分别标识，即使指向同一会话，旧目标的离开回调也不能关闭新预览
- 点击或拖动标签、打开项目选择器、父窗口关闭或预览失效时清理预览及异步工作
- 入场、退出和中途反向从当前可见程度继续；画面、边框、阴影和内容一起位移、淡出
- 系统减少动态效果设置优先，不能靠额外延迟掩盖闪烁

预览画面每 300 ms 刷新，进程检查约每 900 ms 更新；停止预览即停止这条轮询。
原生弹窗只保存展示数据，终端进程仍由 daemon 管理。

## 实现与验证

- `crates/eggie-ui/src/app/terminal_preview.rs`：入口、尺寸、快照和检查生命周期
- `crates/eggie-ui-kit/src/popup_window.rs`：原生窗口、位置、动态尺寸和动画
- `crates/eggie-terminal-view/src/terminal_renderer.rs`：按网格与真实字体指标缩放
- vendored GPUI 的 `PaintMetal` 与 terminal Metal backend：继承 UI 透明度

自动验证非绘制阶段测量并打开窗口、宽/高网格、有限屏幕、缺失快照、窗口复用、关闭后更新与 Metal 透明度。
人工检查在多个侧边栏行和标签间快速移动、同一会话跨入口切换、滚动/拖动、屏幕边缘、
不同字体与缩放倍率，以及退出过程中画面与外框的连续性。自动测试不代替原生弹窗的视觉验证。
